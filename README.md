# TECHNE Apps – Bedienungsanleitung

Kurzanleitung zu den beiden TECHNE-Apps für die tägliche Arbeit:

- **Tagesbericht-App** – Arbeitsbericht von der Baustelle (Handy)
- **Leitstand** – Einsatzplan, Wochenberichte und Planung im Überblick

Die Anleitung ist eine einzelne, in sich geschlossene HTML-Seite mit
Rollen-Umschalter (Techniker / Vorarbeiter). Öffnen: **[index.html](index.html)**
bzw. über die veröffentlichte Seite.
